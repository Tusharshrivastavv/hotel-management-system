# 🏨 Hotel Management System (C++ - OOPs Project)

## 📘 Overview
The **Hotel Management System** is a console-based project built in **C++** that demonstrates the use of core **Object-Oriented Programming (OOPs)** concepts.  
It allows customers to book rooms, view available rooms, and check booking details.  
This project focuses on applying OOPs principles like **Encapsulation, Inheritance, Polymorphism, Abstraction**, and **Composition** in a simple real-world example.

---

## ⚙️ Features
- View all available rooms  
- Book rooms for customers  
- Display all bookings  
- View staff details  
- Interactive menu-driven system  
- Clean and modular C++ structure

---

## 🧠 OOP Concepts Implemented

| Concept | Description |
|----------|-------------|
| **Encapsulation** | Data members of classes are private and accessed through public methods. |
| **Inheritance** | `Customer` and `Staff` classes inherit from the base class `Person`. |
| **Polymorphism** | `showDetails()` function is overridden in derived classes. |
| **Abstraction** | Abstract class `Person` defines a pure virtual function. |
| **Composition** | `Hotel` class contains objects of `Room` and `Booking`. |
